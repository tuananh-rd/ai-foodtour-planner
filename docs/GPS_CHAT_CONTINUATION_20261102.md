# GPS address and conversation continuation contract

Sol owns backend/AI/runtime/review/integration; Antigravity owns dispatched frontend/QA; Claude is a read-only Sonnet5.5 medium adviser. Earlier Luna ownership is superseded. Preserve user3320/API8230; integrate on separate3330/API8240 and live3350/API8250 lanes. No push/deploy.

GPS coordinates remain authoritative for Haversine/Maps. A clicked, disclosed GPS action may add `resolve_address:true` to existing `{type:"location",arguments:{operation:"coordinates",lat,lon,source:"gps"}}`. Without this flag no remote lookup occurs. The server sends rounded (~11m) coordinates only to Photon, never to Gemini or Tavily; no user health, chat or session ID accompanies that request. Response location adds `address_status:resolved|unavailable|not_requested|manual`, `address_provider`, `address_reason`, `attribution`, and an approximate `label`. Show street/place/area as nearby, not a verified house address. Photon house numbers are deliberately excluded. Failure retains usable coordinates, displays unavailable and permits a manual label.

`{type:"location",arguments:{operation:"label",label:"User-provided address"}}` updates the display name only, max160 characters, with no geocoding or coordinate change; existing tour/confirmation are invalidated. Optional `label` on manual coordinates is additive. No automatic origin or arbitrary address geocoding claim.

Photon's official [API/terms](https://photon.komoot.io/) and [project policy](https://github.com/komoot/photon#demo-server) permit reasonable use with throttling and no availability guarantee. Local prototype limits: single nonblocking in-flight lookup; at most one upstream request per1.1s;2s timeout;32KiB response;no redirects/retries;128 in-memory cache entries;positive TTL600s/negative30s;nearest object within500m and Hanoi bounds. Provider can be disabled with `FOODTOUR_REVERSE_GEOCODER=off`; no paid key or additional service. UI includes OpenStreetMap attribution and click disclosure. Public Nominatim was evaluated and not chosen because its public-service personal-data restrictions are unsuitable for this GPS flow.

Gemini may answer general food chat without onboarding and ask at most one meaningful question. Public general-chat dialogue is bounded to six messages; precise origin, location label, health and allergy data are excluded from provider projection. Server remains authoritative for preference/selection/ID/confirmation/CAS. Model/schema/quota failure must retain explicit reason and model/tools/rules provenance. `provider.configured_model` and `response_model` distinguish config from returned model identity; HTTP200/health alone is not quality proof.
